# templates/elementor

Respaldo en JSON de las **plantillas de Elementor** (secciones guardables, Fase 5 N):
`cc-pricing`, `cc-faq`, `cc-authority`, `cc-season-card`, `cc-cta`, etc.

Exportar desde Elementor → Plantillas → Exportar, y versionar aquí el `.json`.
Sirven como copia de seguridad estructural y para clonar en staging/satélites.
El contenido vive en la base de datos; estos JSON son respaldo de estructura.
