# 08 — Fotografía, vídeo y dirección de arte visual

## Objetivo

Este documento define la estrategia oficial de fotografía, vídeo, dirección de arte y optimización visual del proyecto Código Color.

La fotografía no es un elemento decorativo.

Es un activo estratégico de:

- posicionamiento SEO
- GEO
- AEO
- conversión
- autoridad
- branding
- percepción de valor

---

## Principio fundamental

Las imágenes se incorporarán después de aprobar:

- arquitectura
- wireframes
- UX
- CRO
- SEO
- GEO
- AEO
- contenidos
- sistema visual
- dirección de arte

No deben añadirse imágenes durante las fases iniciales del proyecto.

---

## Fase Fotográfica

Una vez aprobada la arquitectura global se ejecutará una fase específica denominada:

### FASE FOTOGRÁFICA

Objetivos:

1. Analizar cada página.
2. Identificar necesidades visuales.
3. Definir función narrativa.
4. Definir función de conversión.
5. Definir requisitos SEO de imágenes.
6. Crear plan fotográfico global.

---

## Calidad visual obligatoria

Toda imagen deberá cumplir:

- alta resolución
- gran contraste
- estética premium
- color intenso
- iluminación cinematográfica
- profundidad visual
- composición editorial

Las imágenes deben elevar el valor percibido de Código Color.
